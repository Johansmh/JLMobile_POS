# JL MOBILE POS

Sistema de ventas e inventario para JL MOBILE (accesorios para celulares, servicio técnico, copias e impresiones).

## Archivos
- `JL Mobile POS.dc.html` — la aplicación (Caja, Inventario, Alertas, Ventas, Cierre de caja).
- `support.js` — runtime necesario para abrir el archivo.
- `image-slot.js` — espacio para el logo.
- `JL Mobile POS v1.dc.html` — versión anterior (estilo original).

## Cómo abrir
Abre `JL Mobile POS.dc.html` en el navegador desde un servidor local (por ejemplo `npx serve .`). Los datos se guardan en el navegador (localStorage).
